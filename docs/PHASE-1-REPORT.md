## 1. สรุป

ระบบจองห้องของฟ้าทะเลรีสอร์ทย้ายจากต้นแบบที่เก็บข้อมูลในไฟล์ JSON ขึ้น PostgreSQL แบบหลายโรงแรม (multi-tenant) แล้ว และมีหลังบ้านครบตามขอบเขต Phase 1 ลูกค้าจองผ่านเว็บได้จริงโดยใช้ราคาและห้องว่างจากฐานข้อมูล ส่วนพนักงานจัดการการจอง ห้อง ราคา และพนักงานได้จากหลังบ้าน การเปลี่ยนแปลงสำคัญต้องให้เจ้าของอนุมัติก่อน

สิ่งที่ยังไม่มีใน Phase นี้คือการรับชำระเงินออนไลน์ (Phase 2) และการส่งอีเมล/LINE (Phase 6) ตอนนี้พนักงานยืนยันการจองเองหลังได้รับเงิน

## 3. การทดสอบ

| ชุด | จำนวน | ผล (2026-11-18) |
|---|---|---|
| Unit (ราคา, กติกา, encoding) | 3 ไฟล์ | ✅ |
| Integration กับ PostgreSQL จริง (role เดียวกับ production) | 6 ไฟล์ | ✅ |
| **รวม Vitest** | **59 tests** | **✅ ผ่านทั้งหมด** |
| E2E Playwright (Chromium, desktop + mobile) | 5 flow × 2 + setup = 11 | ✅ ผ่านในรอบล่าสุดที่รัน (2026-11-17) · รอบนี้ไม่ได้รันซ้ำ เพราะต้องใช้รหัสผ่านเจ้าของของฐานข้อมูล dev — ไม่มีการแก้ UI หลังจากนั้น |
| TypeScript / ESLint | — | ✅ |

การทดสอบที่สำคัญ:
- **จองพร้อมกัน:** 50 คำขอพร้อมกันแย่งห้อง 3 ห้อง → สำเร็จ 3 พอดี
- **Mutation test:** ลบ constraint กันขายเกิน → test ล้ม · ปิดการตรวจชนิดไฟล์รูป → test ล้ม (พิสูจน์ว่า test จับบั๊กได้จริง)
- **แยกข้อมูลโรงแรม:** ไม่ตั้ง tenant = เห็น 0 แถว · อ่าน/เขียน/ลบ/จัดลำดับรูปข้ามโรงแรมไม่ได้ · FK ข้ามโรงแรมไม่ได้
- **จัดห้องพร้อมกัน:** 25 รอบไม่เกิด deadlock (ADR-0010)
- **ใหม่ในรอบนี้:** test รูปห้อง 8 กรณี (ชนิดไฟล์จากเนื้อไฟล์, ขนาด, ไฟล์ปลอม SVG/HTML, path traversal, สิทธิ์ตามบทบาท, audit, ข้ามโรงแรม) และ test การระบุโรงแรมจากโดเมน 5 กรณี
